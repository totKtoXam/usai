# UsAI User Guide

`usai` is a deterministic CLI for reusable AI-assisted development workflows.

It helps projects maintain portable markdown/yaml/json assets:

- prompt templates;
- optional prompt schemas;
- generated prompts;
- rulesets;
- handoff packages;
- future agent exports.

The CLI does not call AI models. It renders files from explicit inputs and project configuration.
