# Rulesets

Rulesets are reusable Markdown rules grouped by task type.

Planned targets:

```text
always
architectural
feature
feature-completion
review
```

Planned sizes:

```text
nano = always-on
mini = task-specific
full = deep audit/reference
```

The default planned source is:

```text
https://github.com/ciembor/agent-rules-books
```

Rules commands are planned for V1 and are not implemented yet.
